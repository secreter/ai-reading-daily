### Hugging Face 开源跨 Agent 框架强化学习方案

同一个模型在不同 Agent 客户端（如 Claude Code 或 Cursor）表现常有很大差异。Hugging Face 推出一套开源方案，跨框架训练让 2.6B 小模型解决率从 42% 提升至 54%。

泛化瓶颈：模型常过拟合特定框架的接口与流程，换环境易直接失效

效率提升：多框架训练后，模型完成相同任务的工具调用减少 31%

实现机制：用代理层拦截交互数据，不修改主流工具的原始代码[>阅读原文](https://mp.weixin.qq.com/s?__biz=Mzk0MDQyNTY4Mw==&chksm=c3833041de010decf484d0ce8689a928250a55caa3168ef1574c06adc51d126b7ca98aac187f&idx=1&mid=2247497054&sn=5ee5e4305633a0a607455c1c47ac73c5)

### 德州大学：思维注入攻击攻破 Agent 达 50%

### Anthropic：多Agent团队常弱于单Agent

哈佛与 Anthropic 联合研究显示，多 Agent 团队常因无人负责全局目标陷入责任扩散，在特定任务中表现比单 Agent 差多达 59 个百分点，换用更强模型也无法消除差距。

瓶颈：成员只顾局部模块而缺少端到端测试

解法：需设跨模块系统负责人并明确验收规范
